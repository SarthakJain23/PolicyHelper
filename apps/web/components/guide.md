# UI Components Guide (`apps/web/components/`)

Modular, accessible, classic UI components for the PolicyHelper web application.

---

## Directory Structure

| Directory                  | Description                                                                                                  | Link                            |
| :------------------------- | :----------------------------------------------------------------------------------------------------------- | :------------------------------ |
| [`ui/`](ui/)               | Core accessible UI primitives based on Radix UI (buttons, inputs, cards, dialogs, selects, tabs, skeletons). | [View `ui/`](ui/)               |
| [`chat/`](chat/)           | Chat session sidebar, message items, streaming cursor, and citation badges.                                  | [View `chat/`](chat/)           |
| [`documents/`](documents/) | Policy upload dropzone, document table, and status badges.                                                   | [View `documents/`](documents/) |
| [`layout/`](layout/)       | Top navigation bar, user avatar menu, and responsive container shells.                                       | [View `layout/`](layout/)       |
